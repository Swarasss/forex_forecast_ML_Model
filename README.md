Forex Forecast Model (Python, Machine Learning)                                                               


• Built a supervised regression model to forecast USD/EUR exchange rates using historical market data from 2015–2025 
retrieved through the Yahoo Finance API. 


• Engineered lagged exchange-rate features and trained a Scikit-learn Random Forest Regressor using the previous trading day's 
closing rate to predict the subsequent closing exchange rate. 


• Evaluated predictions on chronologically held-out data using RMSE and R², achieving an RMSE of 0.0047 and an R² of 
0.9248.
